# Troubleshoot YouTube Run

Translate the first actionable error into plain Vietnamese. State which production step stopped, what already succeeded, whether retry may charge, and the single next action. Prefer Doctor, checkpoint resume, and idempotent retry. Never ask the customer to edit JSON, run shell commands, or delete caches. Escalate to Developer Agent only for a code defect, with snapshot and rollback enabled.
