# Optimize YouTube Tool

1. Ask what single result is most wrong or most valuable to improve.
2. Use run status, artifacts, duration, warnings, and stated budget as evidence.
3. Propose the smallest change that can improve that outcome.
4. Create a new numbered revision; keep the active revision unchanged.
5. Explain expected effect, cost impact, and rollback in plain Vietnamese.
6. Wait for approval, run a one-item pilot, then ask for feedback again.

Never silently mutate the active tool. Never equate a successful job with a satisfactory product.
