# Pilot YouTube Tool

1. Confirm the smallest useful input in chat.
2. Run readiness checks before charging or starting work.
3. Explain paid ShopAPI steps and ask for one run approval.
4. Start with one channel/video/item, not a large batch.
5. Show progress using production-step names.
6. Preserve completed steps on failure and offer resume.
7. Open the product and ask whether it meets expectations.

Do not call a structural validation a real pilot. Do not claim media was created until artifacts exist.
